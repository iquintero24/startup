## Project Set up

1. **Install dependencies:**
```bash
npm install
```

2. **Create the `config.ts` file:**
```bash
npm run config
```

3. **Set the key in `config.ts`:**
```bash
export const API_KEY = "api-key";
```

3. **Start the development server:**
```bash
npm run dev
```

5. **Access the application:**
- http://localhost:5173
